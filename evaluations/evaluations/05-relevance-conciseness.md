# Evaluation 05: Relevance and Conciseness

## User Prompt

What is the difference between RAM and storage on a computer? Answer in two sentences.

## AI Response

RAM is temporary memory that a computer uses to hold data for programs that are currently running. Storage, such as an SSD or hard drive, keeps files and applications even when the computer is turned off.

## Evaluation

**Rating: Accurate**

The response directly answers the question and follows the two-sentence requirement. It correctly distinguishes temporary working memory from persistent storage without adding unnecessary information.

The response is relevant, concise, and appropriate for a user seeking a simple technical explanation.

## Improved Response

RAM temporarily holds data that your computer needs while programs are running. Storage keeps your files, applications, and other data even after the computer is turned off.
